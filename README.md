# 🦊 佛伯乐 · 数字足迹侦察兵 FOX SCOUT

> 找出你自己暴露在网络上的每一寸痕迹 —— 个人数字足迹自查与隐私防护平台

![FOX SCOUT](assets/hero.jpg)

一个**比普通 OSINT 工具更强**的个人数字足迹分析平台：六维足迹模型 + 社工攻击推演 + 泄露事件自查 + 一键防护报告。

**所有分析在浏览器本地完成，不上传任何数据。仅用于分析你自己输入的信息，安全科普用途。**

## ✨ 核心能力

| 能力 | 说明 |
|---|---|
| 六维足迹模型 | 账号暴露 / 密码习惯 / 公开资料 / 社交痕迹 / 位置暴露 / 设备指纹 六维交叉建模 |
| 综合暴露指数 | 0-100 风险评分 + 等级判定（低危 / 中危 / 高危） |
| 泄露事件自查 | 演示算法检查输入标识在历史泄露事件中的暴露情况 |
| 社工攻击推演 | 6 类主流攻击手法（冒充客服 / 撞库 / 钓鱼 / 伪基站 / WiFi 嗅探 / AI 换声诈骗）+ 逐类防守要点 |
| 一键防护报告 | 按暴露面自动生成 P0 / P1 / P2 分级行动清单，可勾选、可复制 |

## 🚀 快速开始

1. 打开在线体验链接
2. 在「侦察终端」输入你自己的邮箱 / 手机号 / 用户名（可混合多个）
3. 点击「启动侦察」，查看六维雷达、暴露评分与泄露自查结果
4. 在「防护指南」勾选完成行动项，生成并复制防护报告

支持键盘回车启动，纯前端单文件，无后端、无注册、无追踪。

## 🎯 为什么更强

- **维度更深**：不只"查一个资料"，而是从 6 个维度量化你的整体数字暴露面
- **风险可量化**：综合暴露指数 + 每个维度的独立评分，薄弱环节一目了然
- **攻防一体**：既展示攻击者如何利用暴露信息，也给出每个手法的具体防守动作
- **结果可行动**：个性化分级清单 + 可复制的防护报告，做完即生效

## 🛡 合规声明

- 本工具仅用于分析**你自己输入**的信息，用于个人信息暴露面自查与网络安全科普
